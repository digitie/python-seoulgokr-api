# 프로젝트 개요

## 한 줄 설명

`kor-travel-transport`는 국내 여행에 필요한 교통정보를 주기적으로 PostgreSQL에 저장하고,
외부 OpenAPI와 내부 통계로 즉시 제공하는 통합 교통정보 라이브러리/API다. `parking-radar`는
현재 그중 공항 주차 데이터를 검증하고 보여주는 웹 대시보드다.

## 문제 정의

- 공항에 출발하기 전에 주차 가능 여부를 확인하기 어렵다.
- 현재 상태만 보면 추세를 알기 어려워, 언제 급격히 혼잡해지는지 판단하기 힘들다.
- 공항마다 주차요금 체계가 달라 대략적인 비용 계산이 번거롭다.

## 목표 사용자

- 자가용으로 공항에 가는 여행객
- 주차 혼잡 패턴을 분석하려는 운영/기획 사용자
- 날짜별, 요일별 주차 패턴을 비교하고 싶은 사용자

## 제품 목표

- 공항·열차·고속도로·도시철도·여객항구·배편 데이터를 같은 수집/저장/조회 경계로
  확장한다.
- 외부 provider 응답을 주기적으로 PostgreSQL에 보존하고, 매 요청 시 원본 API를 다시
  호출하지 않는 OpenAPI를 제공한다.
- 저장된 원본 스냅샷을 이용해 평균, 추세, 혼잡, 가격 등 내부 통계를 제공한다.
- 현재 잔여 주차면을 빠르게 보여준다.
- 최근 7일 10분 간격 과거 시계열을 함께 보여준다.
- 시간대별, 요일별 평균 패턴을 시각적으로 보여준다.
- 10대/50대 임계치 하락 및 회복 시점을 분석한다.
- 입력한 시간 기준으로 주차비를 계산한다.

## 범위

포함:

- 김포, 김해, 제주, 인천 등 공항 데이터 조회
- 공항별 주차장별 현재 상태 조회
- 수집 주기 기반 시계열 저장
- 최근 7일 10분 단위 시계열 집계
- 시간대별/요일별 분석
- 임계치 이벤트 탐지
- 주차요금 계산
- 모바일/PC 반응형 웹
- 현재 구현: `python-krex-api` 고속도로 소통·돌발, `python-opinet-api` Playwright
  주유소·유가·편의정보 수집/저장/조회/통계

제외:

- 로그인/회원 기능
- 개인 맞춤 알림
- 외부 결제 기능
- 인천공항 요금 계산
