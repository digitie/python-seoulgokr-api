# 분석 기준

## 분석 스코프

- 공항 전체 선택:
  - 해당 공항의 활성 주차장을 합산해서 계산한다.
- 세부 주차장 선택:
  - 선택한 주차장 1개 기준으로 계산한다.

이 스코프는 다음 패널에 동일하게 적용된다.

- 현재 잔여 주차면
- 최근 7일 10분 시계열
- 요일 x 시간 평균 잔여 주차면
- 요일 x 시간 평균 잔여 주차면 히트맵
- 최근 8개 공휴일/토요일/일요일 날짜별 시간대 패턴
- 요일별 임계 달성 시간
- 날짜별 임계 달성 시간 히스토리
- 임계치 이벤트

## 시계열

- 기본 범위: 최근 7일
- 기본 간격: 10분
- 기본 미래 축: 없음
- 계산 방식:
  - 각 10분 버킷 시점까지의 최신 상태를 주차장별로 잡는다.
  - 공항 전체 스코프면 같은 버킷의 주차장별 값을 합산한다.
  - `future_hours`를 명시적으로 넘긴 경우에만 미래 버킷을 만들고, 이때 주차값은 이어 붙이지 않고 `lot_observations=0`으로 둔다.

차트 표시 규칙:

- hover / touch 시 해당 시점의 시간과 잔여 주차면을 툴팁으로 노출한다.
- X축은 6시간 단위(`00:00`, `06:00`, `12:00`, `18:00`)로 라벨링한다.
- 보간이나 smoothing 없이 계단형(step) 라인으로 표시한다.
- 차트는 열리자마자 최신 포인트를 활성화하고, 오른쪽 끝 최신 구간이 먼저 보이도록 스크롤한다.
- 차트 제목 바로 아래에 현재 보고 있는 공항 전체 / 세부 주차장 기준을 명시한다.
- 마지막 포인트 값은 화면 상단 `현재 잔여 주차면`과 같은 계산 기준을 사용한다.
- 주차선은 실제 관측값이 있는 구간까지만 그린다.
- 최근 7일 주차 시계열 차트에는 비행편 마커를 넣지 않는다.

## 하루 흐름과 비행편 오버레이

- 주차 시계열 아래 별도 차트로 제공한다.
- X축은 항상 0시부터 24시까지의 하루 시간이다.
- 최근 7일의 잔여 주차면을 날짜별 선으로 겹쳐 보여준다.
- 원하는 날짜의 선을 버튼으로 숨기거나 다시 표시할 수 있다.
- X축 4배 옵션을 켜면 출도착편이 많은 날에도 같은 0~24시 축을 더 넓게 펼쳐 볼 수 있다.
- 선택 공항의 당일 비행편 출도착 시간은 같은 0~24시 X축 위치에 세로 마커로 표시한다.
- 출발편과 도착편 마커는 각각 체크박스로 켜고 끈다.
- 출발편과 도착편을 모두 끄면 비행편 마커를 모두 숨긴다.
- 비행편 마커에는 시간, 편명, 출발공항, 도착공항을 함께 보여준다.
- 출도착 시간, 출발공항, 도착공항이 같은 항공편은 공동운항편으로 보고 하나의 마커로 묶는다.
- 비행편 세로 마커에 마우스를 올리거나 클릭하면 해당 마커를 강조한다.
- 공휴일/토요일/일요일인 날짜의 주차선은 점선과 사각 마커로 일반일과 구분한다.
- 비행편 API 접근 오류는 하루 흐름 오버레이 차트 아래 상태 문구로만 표시하고, 주차 시계열 자체는 계속 렌더링한다.

## 공휴일 표시와 패턴

- 공휴일 데이터는 `15012690` 한국천문연구원 특일 정보 API를 사용한다.
- 공항 이름 옆에는 지난주/이번주/다음주 공휴일을 문장으로 표시한다.
  - 예: `5/5 (화) 어린이날, 5/25 (월) 부처님오신 날 입니다.`
- 최근 7일 시계열 범위 안에 공휴일/토요일/일요일이 있으면 해당 날짜의 차트 배경을 별도 색으로 표시한다.
- 차트 배경 위쪽에는 공휴일명 또는 토요일/일요일명을 표시한다.
- `GET /v1/holidays/summary`
  - 지난주 월요일부터 다음주 일요일까지를 기본 범위로 조회한다.
  - `start_date`, `end_date`를 넘기면 지정 기간으로 조회할 수 있다.
- `GET /v1/parking/analytics/holiday-patterns`
  - 최근 8개 공휴일/토요일/일요일 날짜를 기준으로 시간대별 잔여 주차면을 집계한다.
  - 각 항목은 `day_type`으로 `holiday`, `saturday`, `sunday` 중 하나를 반환한다.
  - 공항 전체 스코프에서는 같은 시각의 세부 주차장 잔여면을 합산해서 시간대 값으로 사용한다.
  - 주차 데이터가 없는 특수일은 24시간 버킷은 유지하되 관측값을 비워 둔다.

## 시간대 평균

### 기존 요약

- `GET /v1/parking/analytics/by-hour`
- 최근 N일 관측값을 시간대별로 단순 집계한다.

### 요일 x 시간 히트맵

- `GET /v1/parking/analytics/by-weekday-hour`
- 최근 N일 관측값을 `요일 x 시간`으로 나눠 집계한다.
- 각 셀은 다음 값을 가진다.
  - `average_available_spaces`
  - `min_available_spaces`
  - `max_available_spaces`
  - `observations`
- UI에서는 잔여면이 적을수록 빨간색, 많을수록 파란색으로 그라데이션을 주고 셀 텍스트는 밝은 배경에서도 읽히도록 고정한다.
- 히트맵 위에는 `평균으로 가장 빠듯한 시간`, `평균으로 가장 여유 있는 시간`을 별도 요약으로 보여준다.

## 임계치 이벤트

기본 임계치는 다음 두 개다.

- 10대
- 50대

이벤트 방향:

- `down`: 임계치 미만으로 떨어짐
- `up`: 임계치 이상으로 회복됨

예:

- `50대 미만 진입`
- `10대 이상 회복`

## 임계 달성 시간 인사이트

- `GET /v1/parking/analytics/threshold-insights`
- 최근 관측 시계열을 기준으로 `50대 미만`, `10대 미만` 진입 시점을 다시 계산한다.

화면에서는 두 형태로 보여준다.

- `요일별 임계 달성 시간`
  - 각 요일에서 임계치 아래로 내려가는 대표 시각
  - 현재는 중앙값 기반 대표 시각을 사용한다.
- `날짜별 임계 달성 시간`
  - 실제 날짜별 진입 시각 히스토리
  - 스크롤 가능한 표로 보여준다.

## 수집 데이터와 분석 데이터

- 원본 수집은 `parking_snapshots`에 저장한다.
- 분석은 가능하면 `parking_snapshots`만 보고 계산한다.
- 원본 API 응답 변화에 덜 흔들리도록, 프론트 계산보다 백엔드 집계를 우선한다.
