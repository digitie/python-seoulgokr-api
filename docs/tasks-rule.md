# tasks.md 작성·운영 규칙

1. `docs/tasks.md`에는 진행 중이거나 예정인 항목만 둔다.
2. 하나의 task는 검증 가능한 결과를 가진 작은 단위로 작성한다.
3. 완료 조건을 만족한 뒤 `[x]`로 바꾸고, 같은 커밋에서 `docs/tasks-done.md`로 옮긴다.
4. 현재 작업과 다음 한 작업은 `docs/resume.md`에 기록한다.
5. 작업 중 발견한 운영 예외·외부 API 상태·타임존·수집 제한은 관련 문서와
   `docs/journal.md`에 남긴다.
6. 문서의 사실은 코드·테스트·운영 확인 결과를 근거로 작성하며 추정 수치를 만들지 않는다.
7. 운영 migration task는 시작 전후의 행 수, 마지막 관측 시각, 마지막 수집 실행 ID를
   비교해 기록한다.
